# Data Dictionary

Sprint 1 defines the expected source schema but does not profile or transform
the data.

## Source Workbook Columns

- `S. No.`
- `ArtisanId`
- `Name`
- `Father's Name`
- `Address (Residence with pin code)`
- `Date of Birth`
- `Gender`
- `Mobile No.`
- `E-mail ID`
- `Product`
- `District`
- `Image URL`
- `Profile URL`
- `Scrape Timestamp`
